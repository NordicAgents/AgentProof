\section{Conclusion}
\label{sec:conclusion}

Static checks on agent workflows are only as credible as the behavioral model
they run on and the applicability of the policy they enforce. In our audit of
$922$ extracted file-level graphs from $252$ public GitHub repositories, the
causes are check-family dependent: graph substitution attributes 68 of 72
non-actionable structural findings to extraction, while it attributes 94 of
112 non-actionable human-gate findings to an inapplicable approval policy.
Conservative removal of every ambiguous legacy file key preserves that split
(66/70 and 84/102, respectively).
Pooling them into one error rate would
make the result depend on how many checks of each family happened to run.

The reverse audit is more consequential. All 12 source-audited HGP-1 violations
escape the mined pipeline, and a source-reconstructed graph recovers only one;
nine regulated effects live inside node bodies outside the graph vocabulary.
Every side-effecting workflow cleared by both graph checks was cleared by a
\emph{placebo} gate. Thus graph reconstruction, policy applicability, and
semantic abstraction coverage are separate validation obligations. The
graph\,$\times$\,DFA product supplies only a scope consequence: on authored
graphs whose event coverage the caller asserts, it can identify a monitor that
cannot fire. This is not an evaluated deployment contribution. We do not
validate the assertion operationally, and no mined graph in this study receives
a \texttt{safe} verdict.

\paragraph{Limitations.}
The frame is public GitHub, not production systems, and two thirds of the
validation sample is tutorial/demo/test code; the unit is an extracted
file-level graph, not an executable workflow root. The 119 files were
quota-selected without randomization, so all proportions describe this audit
rather than a population. Accordingly, the contribution is the observed
failure-mode decomposition for this fixed file set, not a prevalence estimate
or evidence about deployed agents; a probability sample of executable
repository roots is required before either generalization.

The result redirects effort toward higher-fidelity extraction, body-level

\paragraph{Artifact.}
An anonymized artifact is submitted, not promised: the tool, both corpora, the
mining and validation code, committed LLM outputs, reference graphs, justified
triage labels, and deterministic downstream analyses. The original
network-bound mining and LLM passes are not claimed to regenerate offline.

\section*{Ethical Statement}
We mine only \emph{public} GitHub repositories, record exact provenance
(repository at commit SHA plus file path), and redistribute only derived graph
abstractions, never third-party source; no personal data is processed. Findings
classified as defects are disclosed to the affected repositories before
publication, without naming maintainers. Generative AI tools assisted with
language editing, software and claim review, source-triage labels, and
submission-compliance auditing. The authors verified all text, citations, code,
and results, take responsibility for the complete submission, and list no AI
system as an author or scientific source.
