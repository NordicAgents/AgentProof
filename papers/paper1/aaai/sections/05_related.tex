\section{Related Work}
\label{sec:related}

\paragraph{Runtime agent safety.}
NeMo Guardrails~\citep{nemo_guardrails}, Guardrails AI~\citep{guardrails_ai},
LlamaGuard~\citep{llamaguard}, and Rebuff~\citep{rebuff} enforce safety at the
point of LLM output or tool call, catching content-level violations only when the
offending path runs. Sandboxed and adversarial evaluations such as
ToolEmu~\citep{ruan2024toolemu} and AgentDojo~\citep{debenedetti2024agentdojo}
measure agent risk by executing behaviors. Agentproof is complementary to both:
it analyzes structural properties of the topology before deployment, and its
monitor-selection layer (Section~\ref{sec:pruning}) decides which runtime
monitors are even needed.

\paragraph{Concurrent agent-policy systems.}
A concurrent line of work enforces policies at the tool-call boundary with
formal machinery: Agent-C compiles temporal safety specifications to
constraints checked at generation time with conformance
guarantees~\citep{kamath2026agentc}; AgentSpec provides a customizable
runtime-enforcement DSL for safe agent execution~\citep{wang2025agentspec};
ClawGuard and SecureClaw interpose rule sets and authorization boundaries
against prompt injection~\citep{zhao2026clawguard, ma2026secureclaw};
PolicyGuard trains a compact guardrail model for trajectory-level policy
violation detection~\citep{wen2025policyguard}; and AgentFlow builds
cross-framework agent dependency graphs for static security analysis at
scale~\citep{wang2026agentflow}. These systems address \emph{how} to enforce
or analyze; our study measures \emph{when} the static side of that stack pays
off---the base rate of the defects such tools target in public code, and
where the error budget actually sits (model extraction). That measurement is
orthogonal to, and needed by, every system above.

\paragraph{Empirical characterizations of agent defects.}
Recent measurement studies catalogue where agent systems break. AgentAble
derives a defect taxonomy and detector from developer
discussions~\citep{ning2024agentable}; a characterization study of
orchestration-framework bugs identifies nine root causes across roughly
$1{,}026$ bugs~\citep{xue2025bugs}; and a security-debt study reports $221$
vulnerabilities spanning fourteen types in agent
applications~\citep{shen2025securitydebt}. These establish that defects exist
and how they distribute by category. Our study is complementary but asks a
different question: not \emph{which} defects occur, but \emph{how reliably a
static analyzer can recover the behavioral model it needs to find them}, and
what the base rate of a checkable topology-level defect class is once
instrument error is separated from signal. Table~\ref{tab:related} places
these efforts along six axes; the feature that distinguishes ours is a
cross-framework measurement of extraction fidelity, an explicit separation of
estimands, and a provenance-gated soundness guarantee.

\paragraph{Model checking and workflow soundness.}
Classical model checkers---SPIN~\citep{holzmann1997spin},
NuSMV~\citep{cimatti2002nusmv}, CBMC~\citep{cbmc}---verify the same class of
properties but require manual translation into Promela/SMV/annotated~C;
Agentproof extracts the model automatically. Our policy semantics follow LTL
on finite traces~\citep{degiacomo2013ltlf}, with monitoring in the style of
JavaMOP~\citep{javamop} and three-valued LTL runtime
verification~\citep{bauer2011ltl3}. Business-process soundness for Petri
nets~\citep{vanderaalst2011bpm} and BPMN~\citep{dijkman2008bpmn} studies
analogous reachability properties, but targets visual notations rather than the
programmatic API objects agent frameworks expose.

\paragraph{Base rates for static analysis.}
Industrial experience with conventional static analyzers established that
false-positive and actionability rates, not detector cleverness, decide
adoption: Coverity's deployment history~\citep{bessey2010coverity}, developer
studies of why warnings are ignored~\citep{johnson2013static}, and Google's
Tricorder lessons~\citep{sadowski2018lessons}. Our study is the agent-workflow
instance of that genre---and adds a failure mode those studies did not face:
for agent frameworks the \emph{model extraction} step itself dominates the
error budget, so that flag counts on extracted graphs track extractor fidelity
more than any underlying defect rate (Section~\ref{sec:results}).

\paragraph{Agent safety and evaluation.}
Work on agent safety emphasizes alignment, capability evaluation, and
governance~\citep{anthropic_rsp, metr, gabriel2024ethics}. Our contribution is
orthogonal and empirical: base-rate measurements of a specific, checkable
defect class in public agent workflows, with the estimands and their
instrument error separated.
