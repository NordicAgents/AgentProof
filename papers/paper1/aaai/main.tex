\title{Model Extraction Dominates Static Analysis of Agent Workflows: A Cross-Framework Measurement Study}
\author{Anonymous Submission}
\affiliations{}

\begin{abstract}
Static analysis of agent workflows is only as credible as the behavioral model
an extractor recovers from source code: on public agent code, extraction error
dominates check error and can reverse both apparent precision and apparent
defect prevalence. We make this quantitative with a cross-framework measurement
study spanning LangGraph, CrewAI, AutoGen, and Google ADK, mining 922 extracted
file-level graphs from public GitHub and validating a 119-graph sample against
LLM-reconstructed reference graphs (LLM-assisted exploratory labels, not
human-validated ground truth). Measuring a corrected extraction instrument, we
find fidelity is the binding constraint: fixing a single conditional-edge
extractor bug lifts LangGraph edge recall from 0.68 to 0.82 while leaving the
check algorithms untouched. We separate three estimands that a pooled rate
conflates: structural-defect prevalence (1 of 119), human-gate policy-violation
prevalence (3 of 119), and a heterogeneous composite (4 of 119, reported only
as secondary), which post-stratifies to 2.15\% under the corpus's framework
mix. We then give the static machinery two defect-independent jobs: a
provenance-gated certification that returns \texttt{inconclusive} rather than a
false \texttt{safe} on lossy graphs, and a path-sensitive graph\,$\times$\,DFA
product that soundly prunes runtime monitors, yielding a small but nonzero gain
over alphabet-only pruning. The lesson is methodological: report extraction
fidelity alongside every static-analysis claim about agent workflows.
\end{abstract}
