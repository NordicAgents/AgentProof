# AgentProof product documentation

These documents describe how AgentProof can grow from an alpha verification
library into a practical policy-as-code tool for agent workflows.

- [Product vision](product-vision.md) defines the target user, product promise,
  scope, and trust principles.
- [Roadmap](roadmap.md) links the three delivery milestones, the roadmap epic,
  and every implementation issue.
- [Policy design](policy-design.md) proposes a user-facing YAML format and the
  first built-in policy packs.
- [Adoption plan](adoption-plan.md) defines the five-minute experience,
  integrations, success measures, and rollout sequence.

The roadmap is intentionally evidence-driven. AgentProof verifies properties of
the model it extracted or was given; it does not claim that an incomplete model
proves an entire deployed agent safe.
